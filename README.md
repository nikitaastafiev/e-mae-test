# Черновик и песочница для проекта «Ё-Маё»

Это мой тестовый репозиторий. Сюда я заливал код, чтобы проверять, как сайт работает на реальных устройствах через GitHub Pages. 

Код намеренно оставлен «как есть» — со всеми комментариями, закомментированными стилями и экспериментами, которые я проводил по ходу дела. 

## Зачем я оставил этот репозиторий:
* **База знаний для себя.** Здесь лежат закомментированные куски кода, над которыми пришлось долго сидеть.
* **История полировки багов.** В коммитах можно увидеть, как я возился с залипанием ховеров на телефонах, чинил плавный скролл и ловил «слепой шаг» клавиши Tab в слайдере.
* **Эксперименты с дизайном.** Тут видно, как карточки еды менялись от обычных пикселей до автоматических формул с `clamp` и `calc`.

## Что в итоге и планы на будущее:
Проект не заброшен. Если у меня появятся идеи для новых фич или секций — я сначала буду обкатывать их здесь. 

Также планирую возвращаться чтобы, пробовать новые CSS-фичи и ещё сильнее сжимать кодовую базу без ущерба для адаптива. 

Стабильная, вылизанная на текущий момент версия будет перенесена в основной чистый репозиторий.
